# Animesh Info

Professional information website for Animesh Kumar (Software Engineer).

## Stack

- Angular 19
- TypeScript
- SCSS

## Local run

```bash
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Production build

```bash
npm run build
```

Output: `dist/animeshinfo-app/browser/`

## Notes

- No personal photos on the site
- Date of birth is not displayed
- Content sections: Overview, Experience, Capabilities, Education, Contact
